The 3-2-1 rule, applied

  • 3 copies of important data.
  • 2 different media — internal disk plus an external drive, for example.
  • 1 copy off-site — cloud or a drive you keep somewhere else.
Test your backup by restoring one file today. An untested backup is a hope, not a backup — and the moment you discover it did not work is the worst possible moment.

FAQ

How often? Files: weekly at minimum, daily if you work on documents. System image: after big software installs.

External drive or cloud? Both. The drive is fast to restore from, the cloud survives theft and fire.
